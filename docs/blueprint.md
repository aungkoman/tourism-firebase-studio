# **App Name**: Wanderlust Myanmar

## Core Features:

- Homepage: Homepage with hero banner, search, featured destinations, and promotions.
- Destination Pages: Display destinations with visuals and travel tips.
- Region Explorer: Region explorer for browsing destinations by area.
- Attractions & Experiences: Filterable listing of experiences and attractions.
- Promotions Display: Promotions and last-minute deals display.
- AI Trip Itinerary Generator: AI-powered tool to generate personalized travel itineraries based on user preferences and inputs.
- Travel Blog: Blog/articles featuring travel stories and photography.

## Style Guidelines:

- Primary color: Golden yellow (#FFC107) to reflect Myanmar's temples and warmth.
- Background color: Off-white (#F8F8FF) for a clean and modern look.
- Accent color: Soft orange (#FF7043) to highlight important elements and CTAs.
- Clean, modern sans-serif fonts for readability across devices.
- Use detailed outline icons to represent different attractions and regions.
- Responsive grid layout for optimal viewing on all devices.
- Subtle page transitions and loading animations to enhance user experience.
